# 아주한끼

아주대학교 주변의 오늘의 메뉴를 추천하는 PC 우선 반응형 웹사이트입니다.

## 실행

별도의 빌드 도구나 패키지 설치가 필요하지 않습니다. `index.html`을 브라우저에서 열거나, 저장소 루트에서 간단한 정적 서버를 실행하세요.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 현재 구현

- 날짜에 따라 고정되는 오늘의 대표 메뉴
- 이미 본 메뉴를 제외하는 다시 뽑기
- 추천 메뉴 후보 목록 및 주변 식당 지도 검색 링크
- PC 우선 반응형 레이아웃

> 현재 식당명, 가격, 거리, 영업 정보는 화면 확인용 예시 데이터입니다. 실제 식당 정보나 지도 API는 아직 연동되어 있지 않습니다. 지도 링크는 해당 메뉴의 아주대 주변 검색 결과를 엽니다.
